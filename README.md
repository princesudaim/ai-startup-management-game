# Gradient Ascent

Gradient Ascent is a browser-based AI lab management game. Grow a garage lab by balancing compute, training runs, staff, revenue, safety evaluations, and regulatory pressure.

## Play

Play the hosted game at <https://princesudaim.github.io/ai-startup-management-game/>.

## Run locally

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`, or preview it with `npm run preview`.

The game is a static client-side app and requires no account, API key, or backend service.

## New games and saves

Every new game starts with no cash, staff, equipment, unlocked land, trust, or technology progress. The intro offers an explicit $3.4M pre-seed round as the first player action. Game progress is saved in the browser and restored on reload; after an ending, choose **Run it again** to start fresh.
